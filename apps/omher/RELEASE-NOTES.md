AWAKEN BOT 0.1.0 — desktop preview

- AWAKEN BOT branding and an off-black app icon with the ice orb.
- A five-second liquid orb launch screen, with Charcoal or Quiet studio chosen on each launch.
- Awaken Church wordmark and a slower morphing orb inside the app.
- Full-window launch backgrounds with a circular orb at every window shape.
- Readable accent chips and buttons; dark mode defaults on new installations.
- Off-black and off-white dark mode, with warm off-white accents.
- Installers for Apple Silicon Mac, Intel Mac, and Windows x64.
- Signed app updates delivered from the AWAKEN BOT repository, after an explicit release promotion.

Hermes Agent runs locally underneath the app. If it is missing, first launch offers to install it with
its upstream setup. The app uses your existing Hermes bots and your own provider/coding-tool accounts.

These preview installers are not Apple notarized or Windows code-signed. In-app update bundles have a
separate AWAKEN BOT cryptographic signature. Checksums are included with the release.
